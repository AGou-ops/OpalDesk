## 一、本次 `v3.4.2` 重点修复（针对小米平板 6S Pro / HyperOS 3 / 21:9 带鱼屏实机反馈）

1. **彻底根治开启「小米工作台模式 / 强制桌面模式」时，点桌面或打开 App 变成居中方形小窗 (`•••`) 且外接鼠标拖不动窗口的问题**：
   - **根因**：小米平板开启系统「工作台模式」或开发者选项「强制使用桌面模式」后，系统会将默认 `UNDEFINED (0)` 启动的可缩放窗口（含 `LauncherActivity` 桌面自身和默认应用）强行拦截成 `WINDOWING_MODE_FREEFORM (5)` 悬浮小窗；而小米原生小窗顶部 `•••` 手势仅监听平板主屏触摸，不响应虚拟扩展屏鼠标拖拽。
   - **修复**：
     - 扩展屏非分屏启动任务统一显式下发 `WINDOWING_MODE_FULLSCREEN (1)` 与空 `launchBounds`，并将 `VirtualDisplay` 默认容器模式固定为 `FULLSCREEN (1)`；
     - 修正 `TaskInfo` 窗口模式反射读取逻辑（通过 `configuration.windowConfiguration.getWindowingMode()` 精准检测 `FREEFORM = 5`），实时将任何被系统强转小窗的非分屏任务自动剥离 `alwaysOnTop` 并还原为满屏全屏；
     - Dock `⊞ 桌面` 按钮统一走全屏恢复闭环，清理旧版残留的小窗切换分支。
2. **新增 `21:9` 带鱼屏预设 & 智能匹配显示器原生最高 EDID 分辨率**：
   - 分辨率快捷栏新增 **`3440×1440 (21:9 准4K)`** 与 **`2560×1080 (21:9 带鱼)`** 预设；
   - 首次接入显示器及点击 **「↺ 恢复推荐默认」** 时，不再硬编码回退 `2560×1440`，而是自动从显示器 EDID 列表中优选 `≥50Hz` 最高像素原生档位（自动排除 `4K@30Hz` 兼容信号干扰，解决 `3:2` 平板接 `21:9` 显示器默认停在 `2048×1536` 导致两侧留黑边的问题）。

## 二、近期核心能力全览（`v3.3.x` → `v3.4.2`）

- **增强原生镜像信息副屏（14 种预设组件 + 6 套主题 + 系统 AppWidget）**：
  - 支持 **左对齐合并**、**右对齐合并**、**左右双翼对称** 与 **关闭** 4 种布局；内置大数字时钟、电池温压、Wi-Fi 速率信号、蓝牙外设、音频路由通道+音量点按、媒体切歌、日历日程、内存系统负载、实时网速、存储亮度、25 分钟番茄钟、便签、镜像快捷台、`🌙 主屏最低亮度` 共 14 款卡片。
  - 支持 **6 款视觉主题 + 自定义底色**、系统桌面小组件（AppWidget）接入与 **5 档防拉伸比例约束**（`自动原比例 / 方形 1:1 / 竖屏 3:4 / 宽屏 16:9 / 铺满槽位`）。
- **外置鼠标外屏显示、无缝跨屏与「副屏直控」**：
  - 实体鼠标滑过镜像区边缘直接跨入黑边侧边栏操控组件，支持 **5 档光标倍速**（`0.9x ~ 3.4x`）；无键鼠时支持在主屏打开 **`副屏直控` (`SideControlActivity`)** 或使用 **虚拟触摸板** 直接点按小组件。
- **主屏一键黑屏 & 最低亮度省电闭环**：
  - DeX 底部 Dock 快捷浮窗 **「🌙 一键黑屏 (平板最低亮度)」** 与镜像侧边栏 **「🌙 主屏最低亮度」** 卡片：一键压低主屏背光至硬件最低 `1` 并叠加防误触遮罩，双击主屏或退出服务时精确还原亮度。
- **全量底层并发安全、防 ANR 与低功耗优化**：
  - 4 把细粒度并发锁、`SurfaceControl.Transaction` 缓存与显式释放、自适应光标退避轮询、后台线程指标采样、`BridgeProvider` / `BridgeBinder` UID ACL 鉴权与 `ControlReceiver` `goAsync()` 异步响应。

## 三、升级说明

- 直接覆盖安装 `ExtBridge_v3.4.2.apk`，安装后重新激活一次守护进程（Root / 本机无线调试 / 电脑 ADB 任一方式）以加载新版 `extbridge.jar`。
- 若此前 `21:9` 带鱼屏被旧配置存成了 `2560×1440`，升级后在控制台直接点 **`3440×1440 (21:9 准4K)`** 或 **`↺ 恢复推荐默认`** 即可一键铺满。
